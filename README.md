# SÜGEP Academy

[English](#english) · [Français](#français) · [Türkçe](#türkçe)

## English

Founded by Umut Dilsiz in İzmir, Türkiye, SÜGEP Academy helps high school students put the UN Sustainable Development Goals into practice through fieldwork and projects such as the Solar Jacket and biopolymer workshops. The Academy site presents the programmes and student projects. SÜGEP Youth introduces the youth network and its plans for 2027–2030.

[Explore the Academy](https://sugepacademy.org/en/) · [Discover SÜGEP Youth](https://sugepacademy.org/en/youth/)

The site uses HTML, CSS and vanilla JavaScript and runs on GitHub Pages. To preview it locally, run the command below from the repository root and open the address shown.

## Français

Fondée par Umut Dilsiz à İzmir, en Turquie, SÜGEP Academy aide les lycéens à mettre en pratique les objectifs de développement durable de l’ONU grâce à des projets de terrain, comme la veste solaire, et à des ateliers sur les biopolymères. Le site de l’Académie présente les programmes et les travaux des élèves. SÜGEP Youth présente le réseau jeunesse et sa feuille de route pour 2027–2030.

[Découvrir l’Académie](https://sugepacademy.org/fr/) · [Explorer SÜGEP Youth](https://sugepacademy.org/fr/youth/)

Le site utilise HTML, CSS et JavaScript et est hébergé sur GitHub Pages. Pour le consulter en local, exécutez la commande ci-dessous à la racine du dépôt et ouvrez l’adresse indiquée.

## Türkçe

Umut Dilsiz’in İzmir’de kurduğu SÜGEP Academy, lise öğrencilerinin BM Sürdürülebilir Kalkınma Amaçlarını saha çalışmaları, Solar Mont gibi projeler ve biyopolimer atölyeleriyle hayata geçirmesine destek olur. Akademi sitesinde programları ve öğrenci projelerini, SÜGEP Youth sayfasında ise gençlik ağını ve 2027–2030 yol haritasını bulabilirsiniz.
